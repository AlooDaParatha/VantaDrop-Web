# VantaDrop Web

The Vanta Drop online store and its payment server.

- `public/` - the static storefront: product listing and detail pages, cart, checkout, and success and cancel pages. Product photos are in `public/assets/products/`.
- `server/` - the server-side code.
- `vantadrop-stripe-server/` - the Stripe payment server.

The site is deployed to Firebase Hosting (vantadrop1.web.app).

*This repository includes configuration and secrets files. Keep it private.*
